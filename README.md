# 📦 Sistema Inteligente de Gerenciamento de Estoque - Nexora Tech

Este projeto foi desenvolvido pela equipe **Nexora Tech** como solução para o desafio de negócios proposto pela empresa **Difer**, especializada no comércio de aços e metais. O objetivo principal foi substituir os processos manuais e ineficientes de controle de estoque por uma solução digital robusta, ágil e intuitiva.

## 🎯 O Problema Identificado
A empresa Difer enfrentava desafios críticos:
- Controle de estoque desatualizado, gerando inconsistências entre o físico e o sistema.
- Dificuldade e lentidão para consultar produtos disponíveis.
- Processos manuais que aumentavam o risco de erros e desperdício de tempo.

## 💡 A Solução
Desenvolvemos um sistema web que automatiza o controle de materiais. A aplicação conta com:
- Cadastro e atualização de produtos.
- Consulta rápida de disponibilidade em tempo real.
- Geração de relatórios gerenciais precisos.
- Interface amigável para os colaboradores da empresa.

## 🛠️ Tecnologias Utilizadas
- **Backend:** Java e Spring Boot (criação de APIs REST robustas e escaláveis).
- **Persistência de Dados:** Spring Data JPA (mapeamento objeto-relacional).
- **Banco de Dados:** H2 (banco de dados embarcado).
- **IDE:** NetBeans.
- **Versionamento:** Git e GitHub.
